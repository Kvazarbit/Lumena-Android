# Компактні дії та передавання в Companion

Під текстом повідомлення: іконка копіювання, олівець для власного запиту,
стрілка передавання в Companion. Значки 18 dp, окремі області натискання 48 dp
та українські accessibility-підписи. Редагування зберігає попередню поведінку
розгалуження; під час виконання або очікування підтвердження воно вимкнене.

Передавання відкриває вкладку Companion з редагованою чернеткою. Вона містить
точний текст, роль джерела, ID повідомлення, тему, session_id і task_id.
Відповідь Local явно позначена як неперевірений текст, а не результат інструмента.
Чернетка зберігається між перезапусками. Кнопка «Вставити в ChatGPT» вставляє
текст у поточний чат, але не натискає Send. Передавання не копіює весь чат,
не створює підтвердження інструмента й не змінює дозволи.

Нижня навігація доступна також у Local. Обробник Companion залишається в
кореневій композиції Activity, тому зміна Local/Tools/Companion не скасовує його
сканування чи coroutine виконання. Це не foreground service: робота після
знищення процесу Android, перезапуску чи блокування телефона не гарантована.
Стійкий журнал дедуплікації та об'єднана історія проєкту — окремі наступні зміни.

Перевірки на телефоні: іконки для запиту/відповіді/помилки; точний текст чернетки;
редагування й повернення після перезапуску; вставлення без автоматичного Send;
автоматичне read-only виконання після перемикання на Local; ручне підтвердження
запису; повернення до Local без втрати його чату.
