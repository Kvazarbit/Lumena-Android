# Lumena · Semantic Acceptance Guard v1

## Чому це потрібно

Звіт GitHub CI #2166 виконав 16 синтетичних тестів справжніх Kotlin-класів
контролера: 13 PASS, 3 GAP. Підтверджені прогалини:
1. Створення зламаного файлу `Sample.kt` зараховувалось як компіляція.
2. Успішний `image.search` зараховував фотографію автомобіля замість кота.
3. `web.read` стороннього блогу зараховувався як читання потрібного `gov.pl`.

## Нові критерії GoalContract

- **Kotlin-компіляція.** Якщо користувач прямо вимагає, щоб Kotlin/KT код
  компілювався, з'являється критерій `kotlin-compile-verification`.
  Зараз у ToolRegistry немає незалежного Kotlin/Gradle компілятора. Критерій
  навмисно залишається `PENDING`; `file.write` і `python.run` не є доказом компіляції.
  Для `DONE` знадобиться окремо спроєктований та локально верифікований
  компіляційний інструмент. Поки повертати `PARTIAL`, якщо компіляція не доведена.
- **Зображення.** Після `image.search` перевіряємо, чи текстові поля
  `title/alt/description` хоча б одного **конкретного** кадру підтримують
  ключові слова початкової задачі. `matched_query`, вхідний `query`
  та URL не вважаються доказом відповідності. За відсутності доказу
  `visual-metadata-alignment` залишається `PENDING`. Перевірка є
  **лише лексичною**; навіть правдивий заголовок ще не доводить пікселі.
- **Офіційне джерело.** Якщо ціль явно містить домен `gov.pl`, `gov.uk`,
  `gov.au` або інший підтримуваний державний host, потрібен
  успішний `web.read/http.get/http.json` із фінальним HTTPS URL
  цього домену або піддомену. Вхідна URL сама по собі не є доказом
  після редиректу. Підроблений домен на кшталт `gov.pl.evil.example`
  не задовольняє критерій.

## Важливі обмеження

- Перевірка заголовка зображення не є справжньою системою зору.
- Належність URL до державного домену не доводить, що текст сторінки
  відповідає потрібній темі.
- Для локального Kotlin-build не існує зареєстрованого компілятора.
- Кількість PASS у штучному наборі не є виміром когнітивної здібності,
  самонавчання чи якості хмарної/локальної моделі.
- Старі завдання й імпортований досвід — advisory only. Ніщо з цього
  не змінює ToolGate, не обходить підтвердження й не дозволяє дії
  без дозволу власника.

## Як запускати

GitHub Actions запускає `testDebugUnitTest`, під час якого
`CognitiveContourAutonomyLabTest` створює:
- `app/build/cognitive-contour-audit/report.md`
- `app/build/cognitive-contour-audit/results.json`

Ці файли зберігаються в artifact `cognitive-contour-audit`.
У таблиці PASS/GAP залишені окремі adversarial сценарії
`image-title-not-pixel-proof` та `official-host-not-topic-proof`.
Вони не повинні автоматично ставати PASS лише за зміною тексту.

Не merge, не підписувати й не встановлювати APK без прямого дозволу власника.
