# Дозволи Companion для поточного завдання

Companion має окремі явні дозволи для небезпечних інструментів. Самі session_id / task_id
ніколи не є авторизацією: дозвіл виникає лише після натискання кнопки користувачем в APK,
а ToolGate / ToolRegistry перевіряють кожну команду перед виконанням.

## Запис файлів

Для file.write / file.patch є «Дозволити запис для цього завдання…».
Користувач переглядає session/task/model та вводить дозволені відносні шляхи:
по одному файлу в рядку. Зірочка лише наприкінці означає префікс імені в тому самому
каталозі: `aquarium-v2.part*`. Вона не охоплює підкаталоги; необмежений `*` не
приймається. Новий шлях потребує Run once або нового дозволу.

## Python run

Для python.run є окреме «Дозволити Python run для цього завдання…».
Це свідомо високий рівень довіри: Python-код може змінювати файли, запускати процеси
та звертатися до мережі. Після явного підтвердження наступні python.run у тій самій
session_id / task_id / model_id і через той самий bridge можуть виконуватися автоматично
до завершення bounded lease. Дозвіл Python не дає права на file.write/file.patch, а
файловий дозвіл не дає права на python.run.

## Термін, ліміт і збереження

Обидва типи дозволу діють не більше 40 хвилин і не більше 40 автоматичних виконань.
Дозвіл прив'язаний до session_id, task_id, model_id і відбитка поточного bridge URL/token.
Сирий bridge token у сховищі дозволу не дублюється: зберігається лише SHA-256 відбиток.

Дозвіл зберігається у приватних SharedPreferences APK, тому не повинен губитися при
Activity recreation, переходах між вкладками або звичайному перезапуску процесу в межах
його TTL. Після зміни bridge URL/token, завершення TTL/ліміту, помилки або невідомого
результату дозвіл скасовується. Кнопка скасування також видаляє збережений lease, але не
перериває вже запущену команду.

Execution approvals не входять до State Vault backup/restore і не переносяться на інший
пристрій. Safe Auto для read-only інструментів працює окремо.

## Межі

Це не sandbox для Python і не довіра до тексту моделі чи до минулих успішних виконань.
Python lease лише зменшує кількість повторних натискань після свідомої згоди користувача
для конкретного task scope. Registry validation, bridge authentication і bounded limits
залишаються обов'язковими.

Попередній результат згорнуто за замовчуванням; кнопки вставки результату не є запуском
нового запиту. Scan ChatGPT розрізняє відсутнє захоплення, відсутній маркер, неповний JSON
і некоректний формат. Повідомлення не відновлюється з фрагментів різних захоплень.
