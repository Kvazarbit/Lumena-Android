# Дозвіл Companion на запис файлів завдання

У секції Tool request для file.write / file.patch є «Дозволити запис для цього завдання…».
Користувач переглядає session/task, команду та вводить дозволені відносні шляхи:
по одному файлу в рядку. Зірочка лише наприкінці означає префікс імені в тому самому
каталозі: `aquarium-v2.part*`. Вона не охоплює підкаталоги; необмежений `*` не приймається.
Після «Дозволити й продовжити» наступні записи погоджених файлів виконуються автоматично.
Новий шлях потребує Run once або нового дозволу. Новий дозвіл замінює попередній.

Дозвіл зберігається лише в пам'яті процесу, прив'язаний до session_id, task_id,
model_id та поточного bridge URL/token; діє 30 хвилин та не більше 40 автоматичних
записів. Помилка або невідомий результат скасовують дозвіл. Кнопка скасування не
скасовує команду, що вже виконується. Після перезапуску процесу потрібно погодити знову.
ToolGate / ToolRegistry залишаються обов'язковою перевіркою перед виконанням.

Python не входить у дозвіл: обмеження імені скрипта не обмежує його файлові та мережеві
ефекти. Запуск потребує Run once. Safe Auto для читання працює окремо.
Це згода користувача на майбутні записи зазначених файлів, а не довіра до тексту моделі
чи до успішних минулих виконань. Джерелом авторизації є лише натискання кнопки в APK.

Попередній результат згорнуто за замовчуванням; кнопки вставки результату не є запуском
нового запиту. Scan ChatGPT розрізняє відсутнє захоплення, відсутній маркер, неповний JSON
і некоректний формат. Повідомлення не відновлюється з фрагментів різних захоплень.

Обмеження: немає нового каналу передачі великих файлів або фонового сервісу; довгі
повідомлення все ще залежать від Accessibility дерева ChatGPT. Необхідні частини файлів.
Перевірка жестів та доставки на фізичному телефоні потрібна після встановлення APK.
