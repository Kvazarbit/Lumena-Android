# Збережений дозвіл Companion для задачі

У секції Tool request натисни «Дозволити виконання плану…», перевір сесію,
задачу й модель, та вкажи файли/скрипти. Наприклад, для акваріума:

```
aquarium*
verify_aquarium*
run_aquarium*
start_aquarium*
```

Зірочка лише наприкінці означає префікс імені в тому самому каталозі.
Вона не охоплює підкаталоги. Необмежений `*`, абсолютні шляхи та `..` не приймаються.
За потреби увімкни «Автоматично запускати Python-скрипти з переліку».
Перелік обмежує вибір скрипта, а не його дії: Python виконується з правами Termux.
Після «Дозволити й продовжити» записи та погоджені запуски мають спільний дозвіл.
Перехід file.write → python.run → file.patch більше не замінює вид дозволу.

Дозвіл діє до скасування, без ліміту часу чи кількості команд. Він прив'язаний
до session_id, task_id, model_id та bridge URL/token. Новий шлях або контекст
не отримує автоматичного дозволу; APK показує конкретну причину. Зміна task_id
є зміною задачі, навіть якщо текст повідомлення називає її тим самим проєктом.
Для продовження узгодженого плану Companion-запити повинні зберігати ці ID.
Новий дозвіл замінює попередній. «Скасувати дозвіл» не зупиняє вже запущену команду.
ToolGate / ToolRegistry перевіряють кожну команду незалежно від дозволу.

Звичайний відомий результат помилки не скасовує дозвіл, що дозволяє виправлення.
Невідомий результат або перезапуск APK під час незавершеної команди призупиняє
автовиконання до повторного погодження. Ідентифікатор останньої команди
зберігається до запуску та після результату; вона не повторюється автоматично
при відновленні процесу. Це не гарантія exactly-once виконання віддаленого bridge.

Стан дозволу записується атомарно в noBackupFilesDir. Він переживає перезапуск
APK та звичайне оновлення, не переноситься в Android backup чи експорт пам'яті.
Відновлення пам'яті через StateVault очищає дозвіл. Bridge token не дублюється:
зберігається тільки хеш підключення. Старі дозволи 0.12.9 не перетворюються
автоматично на безстрокові: після оновлення погодь новий дозвіл один раз.

Safe Auto для читання та Auto-return result залишаються окремими перемикачами.
Це згода користувача через APK, а не дозвіл із тексту моделі або минулих успіхів.
Фізичну доставку запитів Accessibility та поведінку після оновлення треба
перевірити на телефоні; unit-тести цього не замінюють.
